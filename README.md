# 🪟 Windowz XP

> A little trip to Windows XP — js in your browser btw.

Windowz XP is a browser-based desktop experience inspired by the classic Windows XP look and feel. Boot it up, log in, open apps, drag windows and icons around, and enjoy a slice of the early 2000s.

test it out at : https://ther00tuz3r.github.io/windowz/windowz.html

## ✨ Features

- 🔐 **Boot & login screens** — XP-style startup with a progress bar, a "welcome" splash, and a startup chime
- 🖥️ **Classic XP desktop** with a familiar taskbar, Start menu, live clock, and notification balloons
- 🖱️ **Movable desktop icons** — drag them anywhere, they snap to a grid and remember where you put them
- 📋 **Right-click desktop menu** — arrange icons, make new folders, open apps, start the screen saver
- 🪟 **Window management** — drag, resize, minimize, maximize (double-click the title bar too), and a taskbar button for every open window
- 🧰 **Built-in apps** to play around with:
  - 📝 **Notepad** — open and save `.txt` files, find, insert time/date, word wrap, font size
  - 🧮 **Calculator** — square root, square, reciprocal, memory keys, and keyboard input
  - 🎨 **Paint** — pen, eraser, line, rectangle, oval, fill bucket, color picker, undo, and save as PNG
  - 💣 **Minesweeper** — timer, flags, beginner and intermediate boards, and a safe first click
  - ⌨️ **Command Prompt** — a tiny virtual C: drive with `dir`, `cd`, `md`, `type`, `del`, `echo > file`, plus `ping`, `ipconfig`, `tasklist`, `taskkill`, `color`, and more (type `help`)
  - 📊 **Task Manager** — see your open windows live, switch to them, or end them
  - 🌐 **Internet Explorer** — address bar with back, forward, and home (some sites block being embedded)
  - 🖥️ **My Computer** and a **Run** dialog
- 🎨 **Desktop customization** through Display Properties (Start → Control Panel)
- 🌠 **Screen saver** — a starfield that kicks in after a minute of doing nothing
- 🔌 **Simulated shutdown and logoff**
- 🥚 **Hidden easter eggs** — poke around, especially in the Command Prompt and Calculator 👀
- 💾 No installation needed — just open it in your browser lol

## 🚀 Getting Started

### Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/theR00Tuz3r/windowz.git
   ```
2. Enter the project folder:
   ```bash
   cd windowz
   ```
3. Make sure `wallpaper.jpg` and `logo.png` are in the same folder as `windowz.html` (the desktop background and the Windows logo).
4. Open `windowz.html` in your browser.

That's it. If an image is missing, the wallpaper falls back to a green gradient and the logo falls back to text or an emoji.

> 🔊 The startup chime and sound effects only play after your first click, because browsers don't allow sound before that.

## 🕹️ Take a look around

Log in as **Administrator** (dw therse no password needed lol), open the Start menu, launch an app, shuffle your windows and icons, and see how much of the desktop you remember. Right-click the desktop, try the Command Prompt, and go ahead and click around!
