# 🪟 Windowz XP

> A little trip to Windows XP — in your browser.

Windowz XP is a browser-based desktop experience inspired by the classic Windows XP look and feel. Explore a familiar desktop, open apps, move windows around, and enjoy a slice of the early 2000s.

test it out at : https://ther00tuz3r.github.io/windowz/windowz.html

## ✨ Features

- 🖥️ **Classic XP desktop** with a familiar taskbar and Start menu
- 🪟 **Window management** — drag, resize, minimize, and maximize windows
- 🧰 **Built-in apps** to play around with:
  - 📝 Notepad
  - 🧮 Calculator
  - 🎨 Paint
  - 💣 Minesweeper
  - ⌨️ Command Prompt
  - 📊 Task Manager
  - 🌐 Internet Explorer
- 🎨 **Desktop customization** for a personal touch
- 🔌 **Simulated shutdown and logoff**
- 💾 No installation needed — just open it in your browser lol

## 🚀 Getting Started

### Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/theR00Tuz3r/windowz.git
   ```
2. Enter the project folder:
   ```bash
   cd windowz
   ```
3. Open `windowz.html` in your browser.

That's it.

## 🕹️ Take a look around

Open the Start menu, launch an app, shuffle your windows, and see how much of the desktop you remember. go ahead and click around!
